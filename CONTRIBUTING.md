# Contributing

Thanks for contributing to Advanced Programming, an Extended Learning Course from Denmark.

## Getting started

Review the project README and the relevant source files before making a change. This repository is currently being set up; project-specific build, run, and test instructions will be added when those workflows exist.

## Making a change

1. Keep changes focused and consistent with the surrounding code and documentation.
2. Update documentation when your change affects how the project is used or understood.
3. Run the checks relevant to your change once project checks are available, and report which checks you ran.
4. In your contribution description, explain what changed and note any relevant limitations.

AI agents should begin with [`.github/agent-instructions.md`](.github/agent-instructions.md), which links to the repository's tiered AI context.
